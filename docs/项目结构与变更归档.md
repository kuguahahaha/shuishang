## 三、仓库与部署关系

```
工作区源文件                    部署仓库                  线上
shuishang.html  ──deploy.bat──▶ shuishang-repo/index.html ──▶ kuguahahaha.github.io/shuishang/
water-club.html （本地完整版，不上线）
index.html（原版工具副本）      root-repo/index.html ─────▶ kuguahahaha.github.io（根路径跳转）
```

**同步要点**：
1. 改完 `shuishang.html` → 执行 `shuishang-repo/deploy.bat`（或手动 `cp` + `git commit` + `git push`）
2. 线上更新有 GitHub Pages 构建延迟，**约 15~60 秒**后生效
3. 验证：`curl -s https://kuguahahaha.github.io/shuishang/ | grep <关键标识>`

**本机 Git 注意事项**：
- 便携版 Git 存在 `refs/heads/`、`refs/remotes/` 子目录写入受限的情况 → `git status` 可能显示 `origin/main [gone]`，**不代表远端缺失**，用 `git ls-remote origin` 核实即可
- `git branch --unset-upstream` 可消除 `[gone]` 提示，不影响推送

## 四、后续维护建议

1. **改动前先备份**：`git tag backup/$(date +%Y%m%d-%H%M)` 或先 `git commit` 再改
2. **批量改代码后做三重校验**：① 结构计数（`</html>`/`<script>`/函数数）② 数据回归（四组固定用例）③ 窄屏测量（注入 `body{width:320px}`）
3. **CSS 追加纪律**：先删同选择器旧规则再追加，避免多套规则堆积导致最后改的不生效
4. **方案类文档与实现分离**：`docs/技术方案-*.md` 保留未实现的设计，实现时才动代码
5. **每次会话结束**在 `.workbuddy/memory/YYYY-MM-DD.md` 追加一行结论，避免重复排查
