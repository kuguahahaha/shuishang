# 部署指引 · 飞书云端备份

> 配套：`docs/技术方案-飞书云端备份同步.md`（设计）、`cloudfunctions/recordSync/`（云函数代码）
> 目标：让牌友各自用手机录数据，自动汇总到你的飞书多维表格；**录入过程中界面无任何提示**
> 预计耗时：60~90 分钟（第一次配置）；成本 0 元

---

## 〇、全流程速览

```
第 1 步  飞书建 4 张表            → 拿到 4 个 table_id
第 2 步  飞书建自建应用取凭据      → 拿到 app_id / app_secret
第 3 步  生成口令哈希              → 拿到 2 个 64 位哈希
第 4 步  CloudBase 部署云函数      → 拿到云函数访问地址
第 5 步  网页填地址 + 绑定口令     → 牌友各自绑定一次
第 6 步  试录一场验证              → 飞书里能看到数据
```

---

## 第 1 步 · 飞书建 4 张表

### 1.3 记录 4 个 table_id
打开每张表 → 右上角「…」→ **高级数据权限 / 更多设置** 里能看到「表 ID」（形如 `tblXXXXXX`）
或直接看表格 URL：`?table=tblXXXXXX&view=veXXXXXX` 中 `table=` 后面那串就是 **table_id**。

**记下来备用：**

```
TABLE_SESSIONS = tbl______
TABLE_RECORDS  = tbl______
TABLE_DEVICES  = tbl______
```

### 1.4 记下 app_token
多维表格的 URL 里，`/base/` 后面那串就是 **app_token**：
```
https://xxx.feishu.cn/base/bascnXXXXXXXXXX?table=tblXXXX
                                 ^^^^^^^^^^^^^^^^ app_token
```

## 第 2 步 · 飞书建自建应用取凭据

1. 打开[飞书开放平台](https://open.feishu.cn/) → 登录 → **开发者后台**
2. 「创建企业自建应用」→ 命名随意（如「水上俱乐部备份」）→ 描述随便写
3. 进入应用 → **凭证与基础信息** → 记下
   ```
   App ID     = cli_xxxxxxxxxx
   App Secret = xxxxxxxxxxxxxxxx     ← 这个是密钥，只放进云函数环境变量
   ```
4. 左侧 **权限管理** → 搜索并开通权限：
   - `bitable:app`（多维表格读写）
   - `bitable:app:readonly`（可选）
5. 左侧 **应用发布** → 版本管理与发布 → 创建版本 → **申请发布**（个人版一般直接通过）

> ⚠️ 权限申请不通过的话，可先用「多维表格 → 高级权限」把表格共享给应用作为协作者（应用身份），同样能读写。

## 第 3 步 · 生成口令哈希

口令**只存哈希**，明文永不进代码库。在本机命令行执行：

```bash
# 团队口令（给牌友的）
node -e "console.log(require('crypto').createHash('sha256').update('你的团队口令').digest('hex'))"

# 管理员口令（只有你自己知道）
node -e "console.log(require('crypto').createHash('sha256').update('你的管理员口令').digest('hex'))"
```

得到两个 64 位十六进制串。**建议口令 ≥ 8 位、含大小写和数字。**

```
TEAM_TOKEN_HASH  = 8f14e45fceea167a5a36dedd4bea2543...
ADMIN_TOKEN_HASH = 2c26b46b68ffc68ff99b453c1d304134...
```

> 网页端输入的是**明文口令**，它自己在本地算哈希后只把哈希发出去；云端比对哈希。明文口令两端都不落盘。

## 第 4 步 · 部署 CloudBase 云函数

### 4.1 准备 CloudBase 环境
1. 打开[腾讯云 CloudBase](https://console.cloud.tencent.com/tcb) → 新建环境
   - 环境名随意（如 `waterclub`）
   - **按量付费/免费额度**：环境**必须**是「按量付费」或「包月」，免费版无法部署云函数
   - 地域选离你近的（广州/上海）
2. 进入环境 → 左侧「**云函数**」→ 新建云函数

### 4.2 上传代码
| 配置项 | 值 |
|---|---|
| 函数名 | `recordSync` |
| 运行时 | **Nodejs 16.13 或更高** |
| 执行内存 | 256 MB |
| 超时时间 | 20 秒 |
| 环境变量 | 见下表 |

**代码上传方式（二选一）**：
- **A. 本地上传**：把 `cloudfunctions/recordSync/` 整个目录压缩成 zip，在「代码上传方式」选「本地上传 zip」上传
- **B. 在线编辑**：新建时选「空白模板」，然后把 `index.js` 内容粘贴进 `index.js`（并把 `package.json` 内容粘到同名文件）

### 4.3 配置环境变量
云函数 → 该函数 → **函数配置** → 环境变量 → 添加：

| 变量名 | 值 | 必填 |
|---|---|---|
| `FEISHU_APP_ID` | 第 2 步的 App ID | ✅ |
| `FEISHU_APP_SECRET` | 第 2 步的 App Secret | ✅ |
| `FEISHU_APP_TOKEN` | 第 1.4 步的 app_token | ✅ |
| `TABLE_SESSIONS` | 第 1.3 步的场次表 table_id | ✅ |
| `TABLE_RECORDS` | 第 1.3 步的积分记录表 table_id | ✅ |
| `TABLE_DEVICES` | 第 1.3 步的设备表 table_id | ✅ |
| `TEAM_TOKEN_HASH` | 第 3 步的团队口令哈希 | ✅ |
| `ADMIN_TOKEN_HASH` | 第 3 步的管理员口令哈希 | 选填 |
| `MAX_PER_MINUTE` | `30` | 选填 |

> 🔒 **App Secret 只放在这里**。它永远不会出现在网页代码、GitHub 仓库或任何前端能读到的地方。

### 4.4 配置 HTTP 访问地址
云函数 → **函数配置** → 「HTTP 访问服务」：
- 开启
- 路径：`/record`（随便起，只要不重复）
- 鉴权方式：选择 **「公网访问」/「无需鉴权」**（前端要直接 POST）
  - ⚠️ 安全性靠**口令校验 + 限流**保证，不靠 URL 保密（URL 本来就会暴露在浏览器里）

保存后会生成一个地址，形如：
```
https://<env-id>-<appid>.ap-shanghai.app.tcloudbase.net/record
```
**这个地址就是网页要填的「接口地址」。**

## 第 5 步 · 网页端配置

1. 打开 `Record.html`
2. 滑到「⚙️ 团队协作」块
3. 「团队表格接口地址」填第 4.4 步的地址 → 点「保存」
4. 点「重新绑定口令」→ 输入**团队口令** → 「绑定本机」
   - 提示「已绑定」即成功
   - 若你是管理员：再点「验证管理员」→ 勾选「我是管理员」→ 输入**管理员口令**
5. 牌友：把**团队口令**私下发给她们，她们各自在自己手机上做一次第 3~4 步即可

> 绑定后弹窗**永不再出现**，录入过程中界面**不会显示任何同步字样**。

---

## 第 6 步 · 试录一场验证

1. 网页上录 2~3 个人 → 点「结束录入」
2. 结算面板底部应出现一行：`✓ 已备份到团队表格`
   - 若显示 `⚠ N 条待上传` → 网络或云函数有问题（看浏览器控制台报错）
   - 若显示 `⚠ 访问口令有误…` → 口令哈希对不上，检查 `TEAM_TOKEN_HASH`
3. 打开飞书多维表格 → 积分记录表 → 应能看到刚录的行
4. 场次表应有一行场次信息
5. 设备表应有一行设备记录（设备码、状态=正常）

## 七、运维操作速查

| 需求 | 操作 |
|---|---|
| **换团队口令** | CloudBase 云函数环境变量改 `TEAM_TOKEN_HASH` → 保存 → **全员下次请求被拒**，各自重新绑定一次 |
| **停用某个人的设备** | 飞书设备表找到该设备码 → 「状态」改成「停用」→ 该设备立刻无法写入（60 秒内生效） |
| **看谁在写** | 积分记录表「来源设备」列 ↔ 设备表「设备码」 |
| **改管理员口令** | 环境变量改 `ADMIN_TOKEN_HASH` → 管理员重新验证一次 |
| **查失败原因** | CloudBase 云函数 → 日志查询 |
| **暂停备份** | 飞书设备表把状态改成「停用」；或把网页的接口地址清空（退回纯本地模式） |

## 八、常见问题

**Q：飞书表里看不到数据？**
1. 网页结算面板那行显示的是「✓ 已备份」还是「⚠ 待上传」？
2. CloudBase 云函数日志里有报错吗？
3. 环境变量 6 个必填项都填了吗（尤其 `FEISHU_APP_TOKEN` 很容易漏）？
4. 飞书应用权限申请通过了吗？

**Q：牌友提示「访问口令有误」？**
口令哈希必须与网页输入的明文一致。核对方式：把她的**明文口令**在本地跑一次 SHA-256，和环境变量里的值比对。

**Q：提示「该设备已被停用」？**
设备表里那台设备的状态是「停用」，改成「正常」即可（60 秒内生效）。

**Q：会不会把我的表格写乱？**
不会。写入用唯一键 upsert（`记录键 = 场次ID|昵称`），同一条重复推送只会覆盖，不会产生重复行。

**Q：换手机了？**
新手机打开网页 → 填同一个团队口令绑定一次即可（老手机的记录还在老手机里，云端也有）。

## 九、安全自查清单

- [ ] `App Secret` 只在云函数环境变量里，**不在**网页代码、**不在** GitHub 仓库
- [ ] 团队口令 ≥ 8 位且不与管理员口令相同
- [ ] 管理员口令只自己知道，没发群里
- [ ] 飞书表格权限：仅管理员可编辑，牌友如需查看给「可阅读」
- [ ] 设备表每月扫一眼，有陌生设备就停用
- [ ] 重要场次仍导出 PNG/JSON 存档（备份的备份）
