## 关键口径（当前有效，v1.3.0 起）

```
可抵张数   = min(使用黄卡张数, 桌面筹码 ÷ 20000 向下取整)   ← 手上筹码按整张卡抵扣
结算筹码   = 桌面筹码 − 可抵张数 × 20000                    ← 恒 ≥ 0
积分       = 结算筹码 ÷ 2000（显示 2 位小数）
决算分     = floor(积分)                                    ← 最终成绩
需还筹码   = 使用黄卡张数 × 20000
需补筹码   = 需还筹码 − 已抵扣（整张卡计）
支付金额   = 抵不掉的张数 × 10 元
使用黄卡张数范围：0 ~ 7（整数）
```

