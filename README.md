# 水上俱乐部 · 筹码积分结算工具

朋友之间打牌娱乐后的筹码结算工具：填筹码数量 → 自动算积分 → 黄卡现金结算。
纯前端单文件，**不做任何存储**，刷新即清空。

## 在线访问

https://kuguahahaha.github.io/shuishang/

## 功能

### 筹码面额（页面排列顺序：500 → 1000 → 5000 → 1W ‖ 5W → 10W → 100）

| 颜色 | 面额 |
|---|---|
| 🔵 蓝 | 500 |
| 🟣 紫 | 1000 |
| 🩷 粉 | 5000 |
| ⚫ 黑 | 10000（1W） |
| 🟠 橙 | 50000（5W） |
| 🟡 金 | 100000（10W） |
| 🟢 绿 | 100 |

> 窄屏（手机）下排成两行：第一行 500 / 1000 / 5000 / 1W，第二行 5W / 10W / 100（居中）。

### 页面结构

```
淡蓝框  时间（日期+时间） + 桌号 / 位置 / 昵称
淡蓝框  7 个面额 + 使用黄卡 / 剩余黄卡 + 桌面筹码 / 结算筹码
浅橙框  积分决算：积分结算 / 取整数倍
浅粉框  黄卡结算：归还筹码 / 需补筹码 / 支付
        [ 重置数据 ]  ← 吸底常驻，任何屏幕都可见
```

### 积分换算

```
桌面筹码 = Σ(面额 × 数量)
已抵扣   = min(使用黄卡张数, 桌面筹码 ÷ 20000 向下取整) × 20000   ← 按整张卡抵扣
结算筹码 = 桌面筹码 − 已抵扣
积分     = 结算筹码 ÷ 2000
决算分   = floor(积分)
```

- 「积分结算」显示精确值（保留 2 位小数，四舍五入）
- 「取整数倍」显示向下取整后的最终决算分

### 黄卡结算（已确认口径）

- 1 张黄卡 = 1 手 = 2W 筹码 = 10 积分
- **使用黄卡 ⇄ 剩余黄卡**：互斥联动，两者之和 = 7 张
- **使用黄卡张数范围：0 ~ 7**（超出即报错停止计算）
- **抵扣规则**：手上筹码先按整张卡抵扣（1 张 = 2W 筹码）
- **结算筹码** = 桌面筹码 − 已抵扣（恒 ≥ 0）
- **归还筹码** = 使用黄卡张数 × 20000
- **需补筹码** = 归还筹码 − 已抵扣（整张卡计）
- **支付金额** = 抵不掉的张数 × 10 元

**三个场景实测**

| 场景 | 桌面筹码 | 使用黄卡 | 已抵扣 | 积分结算 | 取整数倍 | 需补 | 支付 |
|---|---|---|---|---|---|---|---|
| 一：没动黄卡 | 150000 | 0 张 | 0 张 | 75.00 | 75 | 0 | ¥0 |
| 二：筹码够抵 | 147000 | 3 张 | 3 张（60000） | 43.50 | 43 | 0 | ¥0 |
| 二：你的例 | 147000 | 7 张 | 7 张（140000） | 3.50 | 3 | 0 | ¥0 |
| 三：筹码不够抵 | 50000 | 7 张 | 2 张（40000） | 5.00 | 5 | 100000 | ¥50 |

> 场景三口述：手上 5W 可抵 2 张（4W），还剩 1W = 10000 ÷ 2000 = 5 分，抵不掉的 5 张 → 买 5 张黄卡 = ¥50。

### 其他

- 桌号 / 位置 / 昵称三个输入框（仅标记用，不参与计算、不存储，刷新即清空）
- 底部「重置数据」吸底常驻，一键清空所有输入
- 手机 / 微信内置浏览器适配（含微信 X5 字体放大防挤压），无外部依赖（球球为纯 CSS 径向渐变绘制）

## 本地使用

直接双击 `index.html` 即可，无需服务器、无需联网。

## 部署

源文件位于上级目录 `shuishang.html`，通过 `deploy.bat` 同步到本仓库 `index.html` 后推送。
GitHub Pages 构建延迟约 15~60 秒，验证：

```bash
curl -s https://kuguahahaha.github.io/shuishang/ | grep wcNetChips
```
