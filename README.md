# 水上俱乐部 · 积分结算工具

朋友之间打牌娱乐后的筹码结算工具：填筹码数量 → 自动算积分 → 补购卡（黄卡）现金结算。纯前端单文件，不做任何存储，刷新即清空。

## 功能

### 筹码面额（从大到小）

| 颜色 | 面额 |
|---|---|
| 🟡 金 | 100000（10W） |
| 🟠 橙 | 50000（5W） |
| ⚫ 黑 | 10000（1W） |
| 🩷 粉 | 5000 |
| 🟣 紫 | 1000 |
| 🔵 蓝 | 500 |
| 🟢 绿 | 100 |

### 积分换算

```
筹码总值 = Σ(面额 × 数量)
净筹码   = 筹码总值 − 补购卡张数 × 20000
积分     = 净筹码 ÷ 2000
决算分   = 积分向下取整（Math.floor）
```

- 左下「积分结算」显示精确值（4 位小数）
- 右下「取整数倍」显示向下取整后的最终决算分

### 补购卡（黄卡）结算

- 1 张补购卡 = 1 手 = 2W 筹码 = 10 积分
- **补购卡张数 ⇄ 剩余张数**：互斥联动，两者之和 = 目标张数（默认 7）
- **归还目标**：7 张 ⇄ 140000 筹码，可填，二选一联动
- **应付金额** = `ceil((需还筹码 − 筹码总值) ÷ 20000) × 10` 元，不足 1 手按 1 手计
- 还清时显示绿色「无需补款，多余 X 筹码」

### 其他

- 昵称输入框（仅标记用，不参与计算、不存储）
- 补购卡张数支持负整数（表示加回 / 退卡）
- 手机 / 微信内置浏览器适配，无外部依赖（CSS 球球为纯 CSS 径向渐变绘制）
